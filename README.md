# Wingtale

Ein gemütliches Voxel-Abenteuer mit abgerundeten Blöcken und Pip, deinem Gleitbeutler.

## Herunterladen

**[Wingtale-Launcher.exe herunterladen](https://github.com/yungalet/wingtale-releases/raw/main/Wingtale-Launcher.exe)** (Windows 10/11, ca. 2,3 MB)

1. Launcher herunterladen und starten. Eine Installation ist nicht nötig.
2. Windows zeigt eventuell „Der Computer wurde durch Windows geschützt“: auf **Weitere Informationen → Trotzdem ausführen** klicken (der Launcher ist nicht kostenpflichtig signiert).
3. Der Launcher lädt das Spiel und hält es automatisch aktuell.

Spielstände liegen unter `%APPDATA%\Wingtale\welten`, die Spieldateien unter `%LOCALAPPDATA%\Wingtale\spiel`.

## Steuerung

WASD laufen · Leertaste springen · Strg sprinten · Maus links halten: abbauen · Maus rechts: setzen · 1–9 / Mausrad: Hotbar · E: Inventar & Herstellen · Q: wegwerfen · G: Kreativmodus · F: fliegen (kreativ) · F3: Infos
